The platform, explained in screens

This is the Healthcare Interoperability Learning Platform: one Spring Boot deployable that takes in HL7 v2 messages, keeps clinical resources in a HAPI FHIR R4 server, and keeps operational metadata in its own PostgreSQL database. The set you are reading explains the same system as the markdown docs, but with controls, diagrams, and animation instead of walls of prose.
