API links

  • GET /api/patients?name= — /api/patients
  • GET /api/patients/{id} — raw FHIR JSON for one patient
  • GET /api/observations?patient= — /api/observations
  • GET /api/observations/{id} — raw FHIR JSON for one observation
  • GET /api/encounters — /api/encounters
  • GET /api/practitioners — /api/practitioners
  • GET /api/demo/validate?resource=... — FHIR validation demo
  • GET /api/demo/live-patient/{id} — live fetch from hapi.fhir.org (never writes to H2)
  • GET /api/hl7v2/parse — parse bundled ADT^A01
  • POST /api/hl7v2/parse — parse posted HL7v2 body
  • GET /api/hl7v2/to-fhir — ADT sample converted to FHIR Patient
  • POST /api/hl7v2/generate?patient={id} — build ADT^A01 from a stored patient
